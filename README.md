# ZELUNARA Signal

Prototype frontend sécurisé en mode démonstration.

## Démarrage

1. Installez Node.js 20 ou une version plus récente.
2. Ouvrez un terminal dans ce dossier.
3. Exécutez `npm install`.
4. Exécutez `npm run dev`.

## Vérification

- `npm run typecheck`
- `npm run build`
